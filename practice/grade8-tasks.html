W1

Vector vs bitmap & the SVG file

벡터 vs 비트맵 · SVG

Mission 1 — Zoom test

Skill: vector vs bitmap, resolution independence
  • Open any photo (a bitmap) and zoom in to 800%. Look at the edges.
  • In Inkscape draw a circle and zoom in to 800%. Look at the edges.
  • Write one sentence using whereas to compare what you saw.

Mission 2 — Edit the SVG code

Skill: reading SVG code · open the live SVG editor or Notepad + a browser
  • Change a circle’s fill to a new colour.
  • Make the circle bigger by changing r.
  • Move a rectangle right by changing x.
  • Add a stroke and stroke-width to one shape.
  • Put one shape on top of another by changing the order of the lines.
Exit ticket — answer first, then open
  1. A bitmap image is made of ______. A vector image is made of ______.
  2. Give one reason a school badge should be a vector, not a photograph file.
  3. What is the difference between fill and stroke?
Answers

1) pixels / mathematics (objects) · 2) it can be enlarged to any size and stay sharp · 3) fill = inside colour, stroke = outline.

W2

Precision beats eyeballing

정렬 · 분배 · 그룹

Mission 1 — Coin Trail

Skill: duplicate, Align, Distribute · Save as Surname_W02.svg
  • Draw one gold coin — a yellow circle with a smaller circle inside. Select both, Ctrl+G.
  • Ctrl+D four times. Drag each copy clear — they land directly on top.
  • Select all five (Shift+click). Align → Centre on horizontal axis.
  • Still selected: Distribute → Make horizontal gaps equal.

Mission 2 — Robot Squad

Skill: group, ungroup, resize
  • Build a robot from rectangles. Select all its parts → Group.
  • Duplicate the robot twice. Shrink two copies into sidekicks.
  • Ungroup the leader and recolour one part.
  • Drag each robot — does it stay in one piece?
RuleSelect more than one object before touching the panel. One object aligns to nothing. Distribute buttons greyed out = fewer than three objects selected.
SupportMission 1 only; three coins is enough to distribute.
CoreBoth missions, saved as Surname_W02.svg.
StretchDistribute vertically into a grid; Align relative to Page; find out what Ctrl+Alt+D does.
Exit ticket — answer first, then open
  1. Explain the difference between Align and Distribute. [2]
  2. Five coins, wobbly line, uneven gaps. Which tool first, and why? [2]
  3. What does Ctrl+G do, and why is it useful when building a robot? [1]
Answers

1) Align lines objects up along an edge or centre; Distribute makes the spaces between them equal. 2) Align first — there is no point evening out gaps in a line that is not straight. 3) It groups objects so they move and resize as one.

W3

Cut, melt and combine

경로 연산

Mission 3 — Cloud, Moon, Castle Rook

Skill: Path › Union, Path › Difference, stacking order · Save as Surname_W03.svg
  • The Cloud — 3 circles + 1 rectangle overlapping → select all → Path › Union.
  • The Moon — 2 circles, one over the other → select both → Path › Difference.
  • Castle Rook — draw the tower parts → Align to centre → Path › Union.
  • Draw a cross, place it on the tower → Path › Difference to cut it out.
  • Recolour, group and save.
The top shape is the cutterIn Difference the shape on top cuts and then disappears. Wrong part cut? Undo, press Page Down on the top shape and try again. The result keeps the bottom shape’s colour.
SupportCloud and Moon only; use two very different colours so the top shape is obvious.
CoreAll three; drag each one to test it is one object.
StretchA heart from only Union (two circles + a rotated square); try Intersection and Exclusion; make a keyhole with two Differences.
Exit ticket — answer first, then open
  1. In Path › Difference, which shape does the cutting, and what happens to it? [2]
  2. Name the operation that melts shapes into one outline. [1]
  3. Your Difference cut the wrong part away. What do you check first? [2]
Answers

1) The top shape cuts, and it is used up / disappears. 2) Union. 3) The stacking order — which shape is on top; fix it with Page Up / Page Down.

W5

Bend the maths — nodes and the Bezier pen

노드 · 베지어

Book cover — James and the Giant Peach

Skill: Object to Path, Node tool, corner vs smooth nodes, Bezier pen · Export a PNG before you leave
  • Task 1 — Magic Peach: orange circle → Path › Object to Path (Ctrl+Shift+C) → N → drag nodes and handles until it looks lopsided and natural.
  • Task 2 — Leaf: Bezier pen (B). Click, do not drag to make sharp corners. Enter to finish.
  • Task 2b: Node tool — select a few points → Make selected nodes smooth. Leave others sharp.
  • Task 3: rectangle background; move the peach and leaf on; group those two.
  • Task 3b: Text tool (T): James and the Giant Peach / Roald Dahl. Page Up if anything hides.
  • File › Export → PNG → Export As.
Press N and see no nodes?You skipped Object to Path. A circle has no editable nodes until it is converted.
SupportTask 1 only — one convincing peach is a full lesson.
CoreAll three tasks; at least one smooth and one corner node in the leaf.
StretchConvert the title text to a path and bend the letters; draw a stem with only smooth nodes.
Exit ticket — answer first, then open
  1. You draw a circle and press N, but no nodes appear. What did you forget? [1]
  2. Describe the difference between a corner node and a smooth node. [2]
  3. With the Bezier tool, why click rather than drag? [2]
Answers

1) Path › Object to Path (Ctrl+Shift+C). 2) Corner = sharp point, handles move independently; smooth = flowing curve, handles locked in a straight line. 3) Clicking makes sharp points you control and can curve later; dragging makes curves straight away and is harder to control.

W6

Trace, wrap and outline

따라 그리기 · 경로 위 텍스트

Logo tracing and typography

Skill: layers, opacity, lock, Text › Put on Path, Path › Linked Offset · Export a PNG
  • Find a simple logo and File › Import it.
  • Layers panel: opacity 50%, then click the padlock.
  • Add a new layer above → Bezier (B) → trace point to point.
  • Circle (stroke on, fill off) + your team name → select both → Text › Put on Path.
  • Select the circle → set its stroke to None. The guide vanishes; the curve stays.
  • Group everything → Path › Linked Offset → drag the diamond out → Page Down.
  • Under your screenshot, write which logo you traced (credit it).
Copyright ruleTracing a brand logo to learn the skill is fine for classwork. Selling it, publishing it or claiming it as your own design is not.
SupportTrace a straight-edged shape (shield, star); skip Linked Offset.
CoreAll three techniques; guide circle stroke set to None.
StretchThe School Crest; a second line of text curving the other way; two Linked Offsets in different colours.
Exit ticket — answer first, then open
  1. Why lower the opacity and lock an imported image before tracing? [2]
  2. Text › Put on Path is greyed out. What did you forget? [1]
  3. Name the operation that creates a thick sticker-style outline. [2]
Answers

1) Fading lets you see your trace against the original; locking stops it moving so the trace stays lined up. 2) You selected only the text, not the text AND the circle. 3) Path › Linked Offset.

Plan · Create · Evaluate

  • Task A — plan on paper: research real examples, sketch 2–3 ideas, annotate what works.
  • Task A — check: read the brief again. Does the sketch meet every requirement?
  • Task B — build: big shapes first → refine with nodes → text last. Use at least four techniques.
  • Task B — describe: name each technique and where it appears, while you still remember.
  • Task C — evaluate: quote the requirements back — met or not met?
  • Task C — feedback: show it to someone; write what they said and what you will change.
Evaluation sentence frames
  • The brief required ______. My design meets this because ______.
  • I used Path › Union to ______, which made ______.
  • One requirement I did not fully meet is ______ because ______.
  • My classmate said ______, so next time I would ______.
