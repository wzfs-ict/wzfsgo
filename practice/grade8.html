01

Vector vs Bitmap

벡터 vs 비트맵

Every digital image is stored in one of two ways. Knowing the difference is the key that unlocks Unit 12 file-format and resizing questions.

Bitmap (raster) image 비트맵 (래스터) 이미지

  • Made of a grid of tiny coloured squares called pixels.
  • The file stores the colour of every pixel.
  • When enlarged, the pixels get bigger, so the image becomes blurry / pixelated.
  • Best for photographs and images with lots of detail and shading.
  • File formats: .jpg .png .gif .bmp

Vector image 벡터 이미지

  • Made of objects (shapes, lines, curves) described by mathematics.
  • The file stores instructions: position, size, colour, line thickness.
  • Can be resized to any size without losing quality — the maths is recalculated.
  • Best for logos, icons, diagrams, cartoons, text.
  • File formats: .svg .eps .pdf (Inkscape saves .svg)

Compare them side by side

Point of comparisonBitmapVector
Made ofPixelsObjects defined by maths
When enlargedLoses quality — becomes pixelatedStays sharp at any size
File sizeUsually large — increases with resolutionUsually small — only the instructions are stored
EditingEdit individual pixelsEdit whole objects (move, recolour, reshape)
Best forPhotographs, realistic imagesLogos, icons, diagrams, text
WeaknessBlurry when enlargedCannot show realistic photo detail easily
Write it like an examiner wants — use “whereas” “A bitmap image is made of pixels, whereas a vector image is made of objects defined by mathematical formulas.”
“A vector logo can be enlarged without losing quality because the shapes are recalculated, whereas a bitmap becomes pixelated.”
Worked example

Q. A school wants a logo that will be printed on a pen and on a large banner. Explain why it should be a vector image. [2]

A vector image is stored as mathematical shapes, so it can be resized to fit both the pen and the banner [1] without becoming blurry or pixelated, because the shapes are recalculated at the new size [1].

Why it scores: one point = what a vector is; second point = the benefit tied to the scenario (pen AND banner). “Vectors are better” scores 0.

Key words: resolution and pixelation

  • Resolution — the number of pixels in an image (e.g. 1920 × 1080). More pixels = more detail = bigger file. 해상도
  • Pixelation — when the individual pixels become visible because a bitmap is enlarged too much. 픽셀화
  • Resolution independent — a vector image does not depend on pixels, so its quality is the same at any size. 해상도 독립적

SVG Code — how a vector is really stored

SVG 코드

An .svg file is just text written in XML. Open one in Notepad and you will see the instructions the computer follows to draw it. Part 1 of your test is all about this.

The coordinate system

  • The point (0,0) is the top-left corner.
  • x gets bigger as you move right.
  • y gets bigger as you move down (not up like in maths!).
  • Shapes written later in the code are drawn on top of earlier ones.

The shapes you must know

ShapeCode exampleAttributes you must recognise
Circle<circle cx="100" cy="100" r="50" fill="red" stroke="black" stroke-width="4" />cx, cy = centre · r = radius
Rectangle<rect x="50" y="50" width="200" height="100" fill="blue" />x, y = top-left corner · width · height · rx = rounded corners
Ellipse<ellipse cx="150" cy="80" rx="100" ry="50" fill="green" />rx = horizontal radius · ry = vertical radius
Line<line x1="0" y1="0" x2="200" y2="100" stroke="black" stroke-width="3" />start (x1,y1) → end (x2,y2). A line needs a stroke or you cannot see it!
Polygon<polygon points="100,10 40,190 190,70 10,70 160,190" fill="gold" />points = list of x,y corners (this one is a star)
Text<text x="20" y="40" font-size="24" fill="navy">Hello</text>x, y = where the text starts · font-size

fillstrokestroke-width

03

Shapes, Duplicate, Group, Align & Distribute

도형 · 복제 · 그룹 · 정렬 · 분배

Precision beats eyeballing. Professional designers never drag shapes into line by eye — they use the Align and Distribute panel.

Core actions

  • Duplicate Ctrl+D — makes an exact copy on top of the original (drag it away to see it).
  • Group Ctrl+G — joins objects so they move and resize as one.
  • Ungroup Ctrl+Shift+G — splits a group back into separate objects.
  • Add to selection Shift+click.
  • Move in a straight line Ctrl+drag.
  • Align & Distribute panel Shift+Ctrl+A (Object › Align and Distribute).

Align is not the same as Distribute

Point of comparisonALIGN 정렬DISTRIBUTE 분배
Question it answersAre they in a straight line?Are the gaps equal?
Minimum objects23
Typical useLine up the tops of three buttonsSpace five coins evenly across a game level
Common optionCentre on horizontal axisMake horizontal gaps equal
“Relative to:” — the setting everyone gets wrong In the Align panel, Relative to decides what the objects line up against. Last selected = the object you clicked last. Page = the edges/centre of the canvas. Selection area = the box around everything selected.
Why nothing happens Only one object selected → Align has nothing to line up with. Distribute buttons greyed out → you have fewer than three objects selected.

Path Operations — Cut, Melt and Combine

경로 연산 (불리언)

All four are in the Path menu. Select two or more overlapping shapes first, or the options stay greyed out.

OperationShortcutWhat it doesExample task
Union 합치기Ctrl++Melts all selected shapes into one outlineCloud = 3 circles + 1 rectangle
Difference 빼기Ctrl+−The top shape cuts a hole in the one below, then disappearsMoon = 2 circles
Intersection 교차Ctrl+*Keeps only the overlapLens / leaf shape from 2 circles
Exclusion 배타Ctrl+^Keeps everything except the overlapChain-link / pattern effects

BIG IDEA — in Difference, the top shape is the cutter

  1. Stacking order decides. Whatever you drew last is on top. Wrong cutter? Don’t redraw — use Page Up / Page Down (or Home / End to jump to the very top/bottom).
  2. The cutter disappears. You end with one shape, not two. If both shapes are still there, the operation did not run.
  3. The colour changes. The result keeps the bottom shape’s colour, because that is what survived. Recolour afterwards.
Worked example

Q. Describe how to make a crescent moon in a vector graphics program. [3]

Draw a circle, then draw a second circle overlapping it, on top [1]. Select both circles [1]. Use Path › Difference so the top circle cuts away part of the bottom circle [1].

05

Nodes, Paths and the Bezier Pen

노드 · 경로 · 베지어 도구

Shapes like circles and rectangles are perfect — and boring. To bend them into something organic you edit their nodes.

Vocabulary

  • Path 경로 — the line joining points; the skeleton of any custom shape.
  • Node 노드 — an exact point on a path; drag it and the shape changes.
  • Handle 핸들 — the lever attached to a node; pull it to bend the line.
  • Object to Path Ctrl+Shift+C — turns a shape into an editable path.
  • Corner node 모서리 노드 — sharp point; handles move independently.
  • Smooth node 부드러운 노드 — flowing curve; handles locked in a straight line, like a seesaw.

BIG IDEA — a circle has no editable nodes until you convert it

  1. Draw the shape as normal.
  2. Path › Object to Path (Ctrl+Shift+C). Nothing seems to happen — that is correct.
  3. Press N for the Node tool. Diamonds (nodes) appear. Click one to see its handles.
  4. Drag nodes and handles to reshape — e.g. turn a perfect circle into a lumpy, organic peach.
If you press N and see no nodes… you skipped Object to Path.

The Bezier pen B

  • Click (don’t drag) to place each point — this gives sharp corners you can curve later.
  • Dragging while clicking makes a curve straight away, which is much harder to control.
  • Press Enter to finish the path · Esc to cancel · click the first point again to close the shape.
  • Use the Node tool toolbar → Make selected nodes smooth / Make selected nodes corner to switch types.
Pro tip Text can also be converted with Object to Path. Designers do this so a logo’s font never changes on another computer that doesn’t have that font installed.

Tracing, Layers, Text on Path & Linked Offset

따라 그리기 · 레이어 · 경로 위 텍스트 · 연결된 오프셋
TRACING 따라 그리기TEXT ON A PATH 경로 위 텍스트LINKED OFFSET 연결된 오프셋
1. File › Import the image1. Draw a circle — stroke on, fill off1. Group the whole design
2. Layers panel: opacity → 50%2. Type the text separately (T)2. Path › Linked Offset
3. Click the padlock to lock it3. Select the text, Shift+click the circle — both selected3. A diamond node appears
4. Add a new layer above4. Text › Put on Path4. Drag the diamond outwards
5. Trace with the Bezier pen (B)5. Set the circle’s stroke to None5. Page Down to send it behind

Why fade and lock the image?

  • Lowering opacity lets you see your own lines clearly against the original.
  • Locking stops the image moving, so your trace stays lined up.
  • Tracing on a separate layer means you can hide or delete the original afterwards.

Copyright — the tracing rule 저작권

  • Tracing a brand logo to practise a skill in class is fine.
  • Selling it, publishing it or claiming it as your own design is not — logos are protected by copyright/trademark.
  • Always credit which logo you traced.
Palette trick Click a colour = sets the fill. Shift+click = sets the stroke. Shift+click the X = removes the stroke. Text upside down on the circle? Rotate the circle, not the text.
Text › Put on Path is greyed out? You only selected the text. Select the text and the path.
07

Your Vector Product — Plan, Create, Evaluate

벡터 결과물 — 계획 · 제작 · 평가

A · Plan

  • Read the brief: who is it for, what is it for?
  • Research real examples.
  • Sketch 2–3 ideas on paper and annotate.
  • Check each sketch against every requirement.

B · Create

  • Big shapes first → refine with nodes → text last.
  • Use at least four techniques.
  • Align, distribute and group sensibly.
  • Check it still reads at icon size.

C · Evaluate

  • Quote the requirements back — met / not met.
  • Name each technique and where it appears.
  • Get feedback from someone else.
  • Say what you would improve and why.
Evaluation sentence frames
  • The brief required ______. My design meets this because ______.
  • I used Path › Union to ______, which made ______.
  • One requirement I did not fully meet is ______ because ______.
  • My classmate said ______, so next time I would ______.

“I like it” or “it looks good” scores nothing — always link back to the requirements.

Practical mock test — Part 3 (20 minutes)

Mock A — the real test format

  • Draw one large yellow star at the top of the canvas
  • Draw three small blue circles below the star
  • Select all three circles → Align them in a straight horizontal line
  • Keep them selected → Distribute so the gaps are exactly equal
  • Draw a curved line with the Bezier tool
  • Type your first and last name with the Text tool
  • Select your name and the curve → Text › Put on Path
  • Screenshot the whole window (PrtSc or Win+Shift+S) and paste it

Mock B — extra practice (same skills, new design)

  • Draw a green rectangle as a hill across the bottom
  • Make a cloud: 3 white circles + 1 rectangle → Path › Union
  • Duplicate the cloud twice (Ctrl+D) and place the copies across the sky
  • Align the three clouds on the same line and Distribute them evenly
  • Make a moon with Path › Difference
  • Convert a circle to a path and use the Node tool to bend it into a bush
  • Write “Night Sky” on a curved path above the hill
  • Group everything and add a Path › Linked Offset border
