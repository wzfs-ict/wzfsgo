File management

파일 관리

Folders and file names 폴더 · 파일 이름

  • Use a hierarchical folder structure — a parent folder with subfolders (e.g. Unit11_Kim › Evidence, Unit11_Kim › Compressed).
  • Give files meaningful names so they can be found quickly — Kim_Unit11_Test.docx, not Document1.docx.
  • Save overwrites the current file. Save As lets you choose a new name, location or file format.
  • Export saves a copy in another format, e.g. a document exported as .pdf.
  • Use Details view in the file manager to see file names, extensions, types and sizes.

Folder screenshot evidence Use Details view so the examiner can see the name, type, size and extension of every file. A cropped corner or Icons view proves nothing.

Why use generic formats?

  • Work can be opened on any computer, whatever software is installed.
  • Files can be shared with people who do not have the same program.
  • Work stays usable if the school changes software later.
  • Generic formats are often smaller than software-specific ones.
Model comparison — .txt and .rtf [3]

A .txt file stores plain text only, whereas a .rtf file can also store formatting [1]. An .rtf file can hold bold, italic, different fonts, sizes and colours, whereas a .txt file cannot [1]. A .txt file is smaller than an .rtf file holding the same words [1].

11.2

Reducing file size — compression

파일 크기 줄이기 — 압축

Why reduce file size?

  • Uses less storage space.
  • Files upload/download faster and web pages load quicker.
  • Fits within email attachment limits.
  • Uses less bandwidth when sent over a network.

How compression works

Lossless compression looks for repetition / patterns and replaces them with short codes: EEEEEEE → E7. A file full of repeated text compresses hugely; a file of random text barely shrinks because there is no pattern to encode.

Point of comparisonLossy 손실 압축Lossless 무손실 압축
What happens to dataSome data is permanently removedData is encoded, then restored exactly when opened
Reversible?No — the original cannot be recoveredYes — the original is returned exactly
Size reductionLargeSmaller
QualityReduced (may not be noticed)Unchanged
Examples.jpg images, streamed video and music.png images, .zip files, text, program files
Suitable forPhotos, video, music — small losses not noticedText, exam marks, programs, spreadsheets — every bit must stay
Model “explain” answer — judging the method [2]

Lossy compression is suitable for a video because the data removed is unlikely to be noticed by the viewer, so a much smaller file is acceptable [1]. It is not suitable for a file of exam marks because removing data would change or lose marks, which means the file would be inaccurate [1].

Reducing an image’s file size (without compression)

  • Reduce the resolution — fewer pixels to store.
  • Reduce the colour depth — fewer bits per pixel, fewer colours.
  • Crop the image — remove unwanted areas so fewer pixels are stored.
Trap If the question says “other than compression”, then “save it as a JPEG” scores 0.

Same picture, three formats — read it like Details view

Percentage reduction = (before − after) ÷ before × 100. For the JPEG: (3692 − 73) ÷ 3692 × 100 = 98.0% smaller — and it still looks the same on screen.

Layout

레이아웃

Editing techniques

  • Highlight (select), delete, move, cut (removes and copies to the clipboard), copy, paste, drag and drop.
  • Place objects: text, images, screenshots, charts, extracts from other documents.
  • Tables: insert and delete rows/columns, merge cells.
  • Table formatting: horizontal alignment (left/right/centre/justified) and vertical alignment (top/middle/bottom), show/hide gridlines, shading, wrap text in a cell, row height and column width.

Headers and footers 머리글 · 바닥글

  • Appear at the top/bottom of every page.
  • Use automated objects (fields) that update themselves: page number, total number of pages, date, time, file name, file path.
  • Align items consistently — e.g. name left, file name centre, page number right — matching the page margins.
  • Typing “Page 1” by hand is not automated — it won’t change on page 2.
  • Zero tolerance: a file name or path typed into a footer scores 0 — it must be inserted as a field.

Text wrapping around images 텍스트 배치

Also: In front of text (covers the words) and In line with text (the image behaves like one large character on the line).

P3

Calculations — file sizes and compression

계산 연습

Show your working: one mark for the method, one for the answer. Round to one decimal place.

  1. A text file is 430 KB. After zipping it is 2 KB. Calculate the percentage reduction.
  2. A second text file is 430 KB. After zipping it is 325 KB. Calculate the percentage reduction, and explain why it is so different from question 1.
  3. A folder is 4,884 KB. Convert this to MB.
  4. A photo is 6.5 MB. How many KB is this?
  5. A PNG is 260 KB and the same picture as a JPEG is 73 KB. By what percentage is the JPEG smaller than the PNG?
Show worked answers
  1. (430 − 2) ÷ 430 × 100 = 99.5%
  2. (430 − 325) ÷ 430 × 100 = 24.4%. The first file repeats the same sentence, so lossless compression can replace each repeat with a short code; the second is random text with no pattern, so there is almost nothing to encode.
  3. 4884 ÷ 1024 = 4.77 MB
  4. 6.5 × 1024 = 6,656 KB
  5. (260 − 73) ÷ 260 × 100 = 71.9%

Toolkit 3/3 · Worked breakdown: Question 9 (Unit 12) 예시 분석

A student changes only the width of a photo from 12 cm to 6 cm. Explain what happens to the photo and how this should have been avoided. [3]
1 Command word 명령어Explain → say what happens and why; use “so” or “because”.
2 Key word 핵심어“only the width” → think aspect ratio (width : height). Don't confuse it with cropping: nothing is cut off, the picture is squashed.
3 Marks 배점[3] → three different points.
4 Parts 부분Two parts: what happens (2 points) + how to avoid it (1 point). Answer both.

5 Plan: 3 points = 3 sentences (계획 — 점 하나에 문장 하나)

[1]Point 1 · What changed?
Only the width was changed, so the aspect ratio was not kept.
[1]Point 2 · What does it look like?
This means the photo is distorted — it looks squashed from the sides.
[1]Point 3 · How to avoid it?
The student should have locked the aspect ratio (or dragged a corner handle) so the height changed in proportion.
6 Check · 확인Both parts answered? ✔ what happens ✔ how to avoid it. “It looks bad” on its own scores 0 — say distorted and why.

Practical tasks — on the computer

실기 과제

These copy the style of the practical papers. Tick each step as you finish. Then check your evidence against the marking points — the examiner can only mark what your screenshot or file shows.

Learn from real marking In a real mock, a student lost 6 of 29 marks even though the document looked right. The two-column gap, the 6 pt spacing and the 7 cm image width could not be proved because there was no screenshot of the settings dialog box. When a task asks for evidence, screenshot the dialog (Margins, Columns, Format Picture, Styles), not just the finished page.

Task A — Folders, saving and formats U11 [8]

  • Create a folder named Unit11_ followed by your family name, e.g. Unit11_Kim. [1]
  • Inside it create two subfolders named exactly Evidence and Compressed. [1]
  • Create a document, type your name and the date, and save it as FamilyName_Practice.docx in the parent folder. [1]
  • Export the same document as FamilyName_Practice.pdf in the same folder. [1]
  • Save another copy as .rtf and another as .txt. Open the .txt — what happened to the formatting? [1]
  • Switch the file manager to Details view with file extensions shown. Record the size of each file with its unit. [2]
  • Take Screenshot 1 showing the folder structure and all files with extensions and sizes. Save it in Evidence. [1]
Marking points
  • Folder and subfolder names exactly as given (capitals, underscore).
  • PDF present in the same folder as the .docx and opens correctly.
  • .txt loses all formatting; .rtf keeps it — expect the .txt to be the smallest file.
  • Sizes recorded with units (KB/MB); screenshot shows the Details view, not icons.

Task B — Compression experiment U11 [6]

  • Make repeated.txt: type one sentence, then copy and paste it until the file is over 100 KB. [1]
  • Make random.txt of a similar size using varied text (e.g. many different paragraphs). [1]
  • Compress each one into its own .zip file and move both zips into Compressed. [1]
  • Record the before and after sizes and calculate each percentage reduction, showing working. [2]
  • Explain why one file compressed far more than the other, and state whether zipping is lossy or lossless. [1]
Marking points
  • Method: (before − after) ÷ before × 100, then the answer.
  • Explanation names the repetition in one file and the absence of a pattern in the other.
  • Zipping is lossless — unzipping returns every file exactly. “Lossy” scores 0 even with a reason.

Task C — Image editing U12 [8]

  • Insert any landscape photo into a new document, below a heading “Weihai Harbour”. [1]
  • Resize it to 10 cm wide, maintaining the aspect ratio. [1]
  • Insert a second copy and crop it so only the left half remains. [1]
  • Rotate the cropped copy 90° clockwise. [1]
  • Screenshot the Format Picture / Size dialog showing the 10 cm width and locked aspect ratio. [evidence]
  • Insert a third copy and reflect (flip) it horizontally. [1]
  • Increase the brightness of the third copy by 20%. [1]
  • Save the original photo as both .png and .jpg; compare the file sizes and say which compression each uses. [2]
Marking points
  • The 10 cm image is not stretched — check the height changed in proportion.
  • Rotate and reflect are different — a reflected image is a mirror image.
  • JPEG smaller (lossy); PNG larger (lossless) but supports transparency.

Task D — Layout U13 [10]

  • Open a document of at least three pages (paste in some text). [—]
  • Header: your name left-aligned, the automated file name centred, today’s automated date right-aligned. [3]
  • Footer: “Page X of Y” using automated page number and total pages, right-aligned. [2]
  • Insert a table with 3 columns and 4 rows. Merge the cells of the top row and type a title in it. [2]
  • Insert a new row at the bottom and delete the middle column. [1]
  • Place an image to the right of the second paragraph with square text wrapping. [1]
  • Move the third paragraph so it becomes the first, using cut and paste or drag and drop. [1]
  • Set the table’s text to vertically centred and hide the gridlines. [1]
Marking points
  • Header/footer items appear on every page and line up with the margins.
  • Page numbers and date are fields (they update) — typed text scores 0.
  • Merged title spans the full table width.
  • Text wraps around the image on the left side; image does not cover any text.
