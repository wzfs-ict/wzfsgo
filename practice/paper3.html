What Paper 3 tests

3번 시험지 개요

Paper 3 is a practical exam on the computer. You get source files, follow numbered instructions, and every instruction carries marks. The examiner marks exactly what you were told to do — nothing more, nothing less.

Paper 3 at a glance

TypePractical, on screen
Time2 hours 15 minutes
SectionsSpreadsheets (Unit 20) · Website Authoring (Unit 21)
EvidenceSaved files, printouts / screenshots in an evidence document

The skills that earn the most marks

  • VLOOKUP / XLOOKUP with an absolute range or named range
  • Nested IF and IF with AND / OR
  • COUNTIF / SUMIF / AVERAGEIF (and the -IFS versions)
  • Printing with formulas visible, row/column headings, fitted to page
  • Search / filter with two criteria, multi-level sort
  • HTML head section, hyperlinks, tables, images
  • CSS rules, classes, generic font families, attaching the stylesheet
01

Practical exam technique

실기 시험 요령

Before you start

  1. Read the whole paper for 5 minutes. Highlight file names, cell references and exact text to type.
  2. Open the evidence document and put your name, centre number and candidate number in it straight away.
  3. Check the files open correctly — CSV files open in the spreadsheet, .html files in a text editor.

While you work

  1. Tick off each numbered step on the question paper as you finish it.
  2. Type text exactly as shown — spelling, capitals and punctuation are marked (accuracy marks).
  3. Save with the exact file name and format asked for (e.g. .csv, .html, .css).
  4. Take screenshots that are readable — zoom in so the examiner can read formulas and code.
The four most common ways marks are lost 1) Formulas not shown in the printout (the examiner cannot award formula marks from values). 2) Relative references that break when replicated. 3) Data entry typos. 4) Missing name in the header/footer of a printout.

Spreadsheets — the essentials

스프레드시트 기초

Why absolute? — a model answer

The discount rate is stored once in cell $L$1. When the formula is replicated down the column, the reference to the cost changes for each row (relative) [1], but the reference to the discount rate must stay pointing at L1, so it must be absolute [1].

Formula basics

  • Every formula starts with =. Operators: + - * / ^; comparison: = <> < > <= >=.
  • Order of operations: brackets → powers → × ÷ → + −. =A1+B1/2 is not the same as =(A1+B1)/2.
  • A formula is a calculation you write (=B2*C2); a function is a ready-made, named formula (=SUM(B2:B9)).
  • Text inside a formula needs speech marks: "Yes". Numbers don’t: 100. Percentages: 10% or 0.1.
  • Replicate = copy a formula down/across using the fill handle so it adjusts for every row.

Nested IF — read it like a ladder

=IF(D2<2,"Short",IF(D2<5,"Half day","Full day"))
  • Test 1: is it under 2 hours? → Short. If not, go to the next IF.
  • Test 2: is it under 5 hours? → Half day. If not…
  • …everything else is Full day. You need one fewer IF than the number of outcomes.
  • Count the brackets: every IF( needs its own ) at the end.

04

Sort, search, format, validate, print

정렬 · 검색 · 서식 · 유효성 검사 · 인쇄

Sort 정렬

  • Select all the data rows (not just one column) or rows will be mixed up.
  • Ascending = A→Z, 0→9. Descending = Z→A, 9→0.
  • Multi-level: “sort by Bike Code ascending, then by Total descending” = two sort levels.

Search / filter 검색 · 필터

  • AND = both conditions true (fewer rows). OR = either (more rows).
  • Operators: > < >= <= <> (not equal).
  • Wildcard * = any characters: M* finds everything starting with M.
  • “Contains” the text = *text*.

Format 서식

  • Currency with 2 dp (e.g. ¥ or $ as asked), percentage, number of decimal places.
  • Bold / italic / font size, merge and centre a title across columns.
  • Conditional formatting — format changes automatically when a condition is true (e.g. red fill if Total > 50).
  • Wrap text, column width so all data is fully visible — truncated data loses marks.

Validation 유효성 검사

  • Range check — between 1 and 12. Type check — whole number. Length check. Lookup/list — must be Y or N.
  • Add an error message that tells the user what is allowed.
  • Test with normal (5), extreme/boundary (1 and 12) and abnormal (20, −3, “ten”) data.

Printing checklist — the most-lost marks on the paper

  • Show formulas not values when asked (formula view) — and widen columns so every formula is fully visible
  • Show row and column headings (A, B, C… 1, 2, 3…) when asked
  • Show gridlines when asked
  • Landscape orientation when asked
  • Fit to one page wide (or one page) when asked
  • Your name, centre number and candidate number in the header or footer
  • Hide only the rows/columns you are told to hide

Relative vs absolute file paths Use relative paths (images/bike.jpg, cycle.css). An absolute path like C:\Users\Kim\Desktop\bike.jpg only works on your computer — once the site is uploaded to a web server, the file cannot be found and the image/stylesheet breaks.

Website Authoring — CSS

CSS 스타일시트
/* cycle.css — external stylesheet: no <style> tags in this file */
body   { background-color: #F0F8FF; font-family: Arial, Helvetica, sans-serif; }
h1     { color: #1F3864; font-size: 32px; text-align: center; }
p      { font-size: 14px; line-height: 1.5; }
table  { border-collapse: collapse; width: 80%; }
th, td { border: 1px solid #333333; padding: 6px; }
.note  { font-style: italic; color: #B42318; }      /* class: any element */
#footer { font-size: 10px; text-align: right; }    /* id: one element */
ul     { list-style-type: square; }

Rules to remember

  • Rule = selector { property: value; } — colon after the property, semicolon after each value.
  • .name = class (can be used many times) · #name = id (once per page).
  • Colours as hex: #RRGGBB, e.g. #FF0000 = red.
  • Always end a font list with a generic family (serif, sans-serif, monospace) — used if the named fonts are not installed.
  • Sizes need units: 14px, 1.2em, 80%. 14 alone is wrong.
  • An external .css file contains no HTML — no <style> tags.

Three places to put CSS — and which wins

WhereExamplePriority
Inline<p style="color:red">Highest
Internal<style>…</style> in the headMiddle*
External<link rel="stylesheet" href="…">Lowest*

*Strictly, between internal and external the one that appears later in the head wins (the cascade). Inline always beats both.

Why external stylesheets? One file styles every page → consistent look, change once to update the whole site, smaller page files.

Web lab — build and fix pages live

웹 실습

Task 1 — Fix the page (6 errors)

This page should show a centred navy heading, a paragraph in a class called note (italic, red), an image with alternative text, and a link that opens in a new window. There are six errors. Fix them all.

Show the six fixes
  1. color: #1F3864 text-align → missing semicolon: color: #1F3864; text-align: center;
  2. #note → .note (it is a class, not an id)
  3. font-family: Arial, Helvetica; → add the generic family: Arial, Helvetica, sans-serif;
  4. </h2> → </h1> (closing tag must match)
  5. <img> has no alt → alt="Red mountain bike"
  6. href="www.example.com" target="blank" → href="https://www.example.com" target="_blank" (full URL and underscore)

Task 2 — Build the price table

Complete the price table using the Rates sheet: add the E-Bike, Mountain Bike and Tandem rows. Notice how the title cell “Weihai Cycle Hire — Prices” spans both columns with colspan="2". Stretch: add a final row with one cell spanning both columns that says “Helmets included free”.

Task 3 — Style it

Write CSS so that: the body background is #F0F8FF; all h2 headings are #0E7C86, 24px, centred, in a sans-serif font; the class price is bold. Then use the class on a paragraph.

Mini mock paper — practical steps (on the computer)

미니 모의고사

Recreate the case-study sheets in your spreadsheet software (or use the file from Schoology). Work through the steps in 45 minutes. Tick each one, then check against the marking notes.

Section A — Spreadsheet (30 marks)

  • 1. Insert a new row above row 1. In A1 enter the title Weihai Cycle Hire — October. Merge and centre it across A1:J1, bold, 16pt. [3]
  • 2. In F3 use a lookup function to return the rate from the named range RATES. Replicate down to F12. [5]
  • 3. In G3 calculate Cost = Hours × Rate. Replicate. [2]
  • 4. In H3 calculate the discount: if Member is Y, Cost × the member discount in L2, otherwise 0. Use an absolute reference. Replicate. [4]
  • 5. In I3 Total = Cost − Discount. Format F:I as currency, 2 dp. [2]
  • 6. In J3 display Short (under 2 hours), Half day (under 5) or Full day. Replicate. [4]
  • 7. Below the data: count members, total takings for E-Bikes, average Total rounded to 2 dp. [6]
  • 8. Conditional formatting: Totals over ¥100 in bold red. [2]
  • 9. Print formulas: landscape, row and column headings, one page wide, your name in the header. [2]

Section B — Website (25 marks)

  • 10. Create cycle.html with title Weihai Cycle Hire, author meta tag (your name), viewport meta tag, UTF-8 charset. [4]
  • 11. Attach the external stylesheet cycle.css using a relative path. [2]
  • 12. Add an h1 heading, a paragraph, and an image bike.jpg 250 pixels wide with alt text, keeping its aspect ratio. [4]
  • 13. Add the price table from Task 2 with the merged title row. [5]
  • 14. Add a link “Book now” to https://www.example.com/book opening in a new window, and an email link to hire@example.com. [4]
  • 15. In cycle.css: body background #F0F8FF; h1 centred, #1F3864, sans-serif; class note italic. [6]
Marking notes for the mini mock
  • Q2 =VLOOKUP(C3,RATES,3,FALSE) — function, C3 relative, RATES/absolute range, column 3, FALSE/0; correct values ¥25, ¥15, ¥35… Accept XLOOKUP with absolute ranges.
  • Q4 =IF(E3="Y",G3*$L$2,0) — IF, condition with "Y" in speech marks, G3*$L$2, 0 for false. Typing 10% instead of $L$2 loses the absolute mark.
  • Q6 =IF(D3<2,"Short",IF(D3<5,"Half day","Full day")) — check a 5-hour hire shows Full day and a 2-hour hire shows Half day (boundaries).
  • Q7 =COUNTIF(E3:E12,"Y") → 5 · =SUMIF(C3:C12,"EB",I3:I12) · =ROUND(AVERAGE(I3:I12),2)
  • Q9 No marks for formulas if the printout shows values; check every formula is fully visible.
  • Q12 <img src="bike.jpg" alt="…" width="250"> — no height (or a correctly scaled height).
  • Q14 target="_blank" and href="mailto:hire@example.com".
