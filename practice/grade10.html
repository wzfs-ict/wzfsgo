How to write answers that score

점수를 받는 답안 작성법

EAL learners: the Answer toolkit breaks a question down step by step, with Korean terms and a worked example.

Marks = points. A 4-mark question needs four separate, correct points — one sentence per mark. Never use brand names: write “operating system” or “word processor”, not a product name.
Command wordWhat the examiner wantsSentence shape
State / Give / IdentifyA short fact or name — no reason needed“Non-volatile.” / “Laser printer.”
DescribeWhat it is / what it does, with detail“A ____ is ____. It is used to ____.”
ExplainA point plus its reason or consequence — a point alone is half“____ because / so / which means ____.”
CompareBoth things in every point“____ is ____, whereas ____ is ____.”
Discuss / EvaluateBoth sides, then a conclusion“One advantage… However… Overall…”

NAME · SAY · TIE — scenario questions

  1. NAME the device or term.
  2. SAY what it does.
  3. TIE it to the scenario in the question.
Example
A chip and PIN reader [name] reads the data on the card’s chip and checks the PIN the customer types [say], so the restaurant knows the card belongs to the customer before taking payment [tie].

Answers that score 0

  • “It is faster / cheaper / better” — faster than what, at what?
  • A brand name instead of the generic term.
  • A compare answer that talks about only one thing.
  • Repeating the words of the question.
  • A safety issue when a health issue is asked (or the other way round).
U1

Types and components of computer systems

컴퓨터 시스템의 종류와 구성요소

Hardware and software

  • Hardware 하드웨어 — the physical components of a computer system.
  • Software 소프트웨어 — programs (instructions) that tell the hardware what to do.
  • Application software 응용 소프트웨어 — lets the user carry out tasks: word processor, spreadsheet, database, presentation, graphics/photo editing, video editing, audio editing, CAD, control software.
  • System software 시스템 소프트웨어 — runs and manages the computer and provides a platform for applications: operating system, utilities, device drivers, compilers, linkers.
  • Utilities — anti-virus, backup, file compression, disk defragmentation, formatting.
  • Trap: control and measurement software is application software — it is the row most often classified wrongly.

Main components

  • CPU 중앙처리장치 — processes instructions and data (fetch–decode–execute). A microprocessor is a CPU on a single chip.
  • Internal memory — RAM and ROM, directly accessed by the CPU.
  • Input devices — put data in; output devices — show/produce results.
  • Backing (secondary) storage — keeps data permanently (HDD, SSD, optical).
  • Inside the case: motherboard, graphics card, sound card, NIC (network interface card).

RAM vs ROM — the most-asked comparison

Model comparison [3]
RAM is volatile, whereas ROM is non-volatile [1]. RAM can be read from and written to, whereas ROM can only be read [1]. RAM stores the programs and data in use, whereas ROM stores the boot-up instructions [1].

Internal memory vs backing storage

Point of comparisonInternal memory (RAM/ROM)Backing storage (HDD, SSD…)

Asked for an example of backing storage? RAM and ROM score 0 — they are internal memory.

Analogue and digital data 아날로그 · 디지털 데이터

  • Sensors measure analogue data — continuously changing values (temperature, sound, light).
  • A computer can only process digital (binary) data.
  • An ADC (analogue-to-digital converter) converts the analogue signal to digital before the computer processes it. A DAC does the reverse, e.g. to drive speakers or motors.
  • Sample rate — how often the analogue signal is measured. Higher rate = more accurate copy of the original, but more samples stored = larger file.
Model answer — why is an ADC needed? [2]

A computer can only process digital data [1], so the analogue signal from the sensor must be converted to digital by the ADC first [1].

“So the computer can understand it” with no data type named scores 0.

The operating system 운영 체제 manages the hardware, memory, files and folders, input/output devices, security (user accounts/passwords), runs applications, handles errors, and provides the user interface.

Emerging technologies

  • Artificial intelligence (AI) 인공지능 — computers that simulate human intelligence: learning from data, reasoning, recognising speech and images. Examples: chatbots, recommendation systems, self-driving cars, medical image analysis.
  • Extended reality (XR) 확장 현실:

Model “explain” — why a laptop uses an SSD [3]
An SSD has no moving parts, so it is less likely to be damaged if the laptop is dropped [1]. It uses less power, so the battery lasts longer [1]. It has faster access times, so the laptop starts and opens files more quickly [1].
  • Backing storage 보조 저장 장치 — non-volatile storage used to keep data permanently (not RAM).
  • Serial / sequential access 순차 접근 — data read in order from the start (magnetic tape). Direct access 직접 접근 — go straight to the data (HDD, SSD, optical).
  • Backup 백업 — a copy of data kept separately (ideally off-site), so it can be restored if the original is lost, corrupted or stolen.
P2

Document production (with styles & proofing)

문서 작성 · 스타일 · 교정

Page layout

  • Orientation — portrait or landscape. Page size — e.g. A4.
  • Margins — top, bottom, left, right (set exact cm when asked).
  • Breaks — page break (start a new page), section break (change layout, e.g. columns or orientation, part-way), column break (move text to the next column).
  • Columns — number of columns, width and the spacing between them.
  • Gutter margin — extra space reserved for binding, separate from the normal margin.

Text and paragraphs

  • Font: serif (with small strokes) or sans-serif (without); size in points; enhancement — bold, italic, underline, highlight.
  • Alignment: left, centre, right, fully justified (straight left and right edges).
  • Line spacing: single, 1.5, double, multiple; spacing before/after paragraphs (in points).
  • Indents: first line, hanging. Tabs: left, right, centre, decimal.
  • Lists: bulleted or numbered; change bullet style and indent level.
  • Superscript/subscript, case changes, Find & Replace (match case, whole words), bookmarks and hyperlinks.

Tables

  • Insert/delete rows and columns, merge cells.
  • Borders (show/hide gridlines), shading, cell padding.
  • Text alignment and wrapping inside cells; column widths so data is fully visible.
  • Tables and lists must not split across pages in the final document.

Headers and footers

  • Automated fields: page numbers, total pages, date, time, file name, file path.
  • Align consistently with the page margins — left, centre, right.
  • Your name, centre number and candidate number where the paper says.
Zero-tolerance rules (from real mock marking)
  • The golden rule: your name, centre number and candidate number must be typed electronically on every piece of evidence before it is printed. Handwriting them on afterwards scores 0.
  • A file name or path typed by hand into a footer scores 0 — it must be an automated field.
  • A rotation is binary: “rotate 90° clockwise” is either done or not. No partial credit.
  • Styles must be built in the Styles pane — print/screenshot the styles list as evidence.

Styles and house style 스타일 · 하우스 스타일

  • A corporate house style sets the fonts, sizes, colours, alignment, spacing and logo placement an organisation always uses.
  • Create named styles (e.g. Title, Subheading, Body) with font, size, colour, alignment, enhancement and spacing, then apply them.
  • Why? Consistency across all documents · recognisable brand image · saves time — change the style once and every heading updates · looks professional.

Proofing 교정

Spell and grammar check — limits

  • Will not find a correctly spelt wrong word (“there/their”, “from/form”).
  • Flags names, technical terms and other languages as errors.
  • May use the wrong dictionary (e.g. US vs UK spelling).
  • Cannot check that the data is correct — only that words are spelt correctly.

Validation vs verification

  • Validation — the computer checks data is sensible / reasonable (range, type, length, format, presence, check digit).
  • Verification — checks data has been copied correctly: visual check (compare with the original) or double entry (typed twice and compared).
  • Valid data can still be wrong: 25 is a valid age, but the person may be 52.
Final checks before you print No widows or orphans (a single line of a paragraph left alone at the top/bottom of a page) · no blank pages · no split tables or lists · consistent spacing between paragraphs · all images inside the margins · header/footer on every page.

Editing a table 표 편집

  1. Insert or delete rows and columns exactly where the task says (e.g. “between Germany and China”).
  2. Sort only the data rows — never the title or header row — into ascending or descending order of the named column.
  3. Merge cells to make a heading that spans the columns, then centre-align it.
  4. Set borders / gridlines to print, add shading if asked, and widen columns so no data wraps.
  5. Apply the named table style and check the table is not split over columns or pages.
Syllabus 2026–2028 Mail merge is not part of the current 0417 syllabus. Focus on page layout, styles, tables, images, headers and footers, and proofing.

P2

Data presentation — presentations

프레젠테이션

Master slide 마스터 슬라이드

  • Sets items that appear on every slide: background, fonts and colours, logo/image, slide numbers, footer text.
  • Why? Consistent look; change once to update all slides; saves time.
  • Items placed on the master cannot be moved accidentally on individual slides.
  • Slide numbers must be automated, inserted on the master.
  • A presentation can be created from a text outline (e.g. an .rtf file) — headings become slide titles.

Slide content and delivery

  • Insert text, bulleted lists, images, charts, tables, video and audio.
  • Transition 전환 — effect between slides. Animation 애니메이션 — effect on an object on a slide.
  • Speaker notes — notes for the presenter, not shown to the audience.
  • Handouts — printed copies for the audience (e.g. 3 or 6 slides per page).
  • Hyperlinks / action buttons — jump to another slide, file or website.
  • Too many effects distract the audience — use them consistently and sparingly.

Toolkit 3/3 · Worked breakdown: Question 1 (Unit 1) 예시 분석

Compare RAM and ROM. [4]
1 Command word 명령어Compare → every sentence talks about both, joined with “whereas”.
2 Key words 핵심어RAM and ROM are easy to mix up: RAM = Random Access Memory (read and write); ROM = Read Only Memory.
3 Marks 배점[4] → four different comparison points.
4 Parts 부분One part, but two things — each point needs RAM and ROM.

5 Plan: 4 points = 4 sentences (계획 — 점 하나에 문장 하나)

[1]Point 1 · Power off?
RAM is volatile (it loses its data when the power is off), whereas ROM is non-volatile.
[1]Point 2 · Read or write?
RAM can be read from and written to, whereas ROM can only be read.
[1]Point 3 · What is stored?
RAM holds the programs and data currently in use, whereas ROM holds the start-up instructions.
[1]Point 4 · Size?
RAM usually has a much larger capacity than ROM.
6 Check · 확인Does every sentence mention both RAM and ROM? “RAM is faster” or “RAM is temporary” on its own scores 0.
