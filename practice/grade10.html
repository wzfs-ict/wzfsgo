How to write answers that score

점수를 받는 답안 작성법
The golden rule: marks = points. A 4-mark question needs four separate, correct points. Write one sentence per mark. Never use brand names — write “operating system”, not a product name.
Command wordWhat the examiner wantsSentence shape
State / Name / GiveA short fact — no explanation needed“Router.” / “It is non-volatile.”
DescribeWhat it is / what it does, in detail“A ____ is ____. It is used to ____.”
ExplainReasons — how and why“____ because ____, so ____.”
CompareSimilarities/differences — both things in each point“____ is ____, whereas ____ is ____.”
Discuss / EvaluateBoth sides (advantages AND disadvantages), then a conclusion“One advantage is… However… Overall…”
RecommendA choice + justified reasons linked to the scenario“I recommend ____ because in this scenario ____.”

NAME · SAY · TIE — for scenario questions

  1. NAME the device/term.
  2. SAY what it does.
  3. TIE it to the scenario in the question.
Example
A barcode reader [name] scans the barcode on each product to read its number [say], so the supermarket’s stock level is updated automatically when the item is sold [tie].

Sentence frames bank

  • Compare: ____ is ____, whereas ____ is ____.
  • Reason: ____ because ____. This means that ____.
  • Advantage: One advantage of ____ is that ____, so ____.
  • Disadvantage: However, a drawback is that ____, which could ____.
  • Recommend: I recommend ____ because ____. Although ____, this is less important because ____.
  • Connectives: whereas · however · because · therefore · so · this means · for example · overall
Answer that scores 0WhyFix
“It is faster / cheaper / easier.”Too vague — faster than what? at what?“An SSD has faster data access times than an HDD because it has no moving parts.”
A brand name (a product or company)Never creditedUse the generic term
Repeating the questionNo new pointAdd the reason or effect
Compare answer about one thing onlyNot a comparisonMention both, joined with “whereas”
Discuss answer with only advantagesOne-sided — cappedGive both sides and a conclusion
U1

Types and components of computer systems

컴퓨터 시스템의 종류와 구성요소

Hardware vs software

  • Hardware 하드웨어 — the physical components you can touch (CPU, monitor, keyboard).
  • Software 소프트웨어 — programs / instructions that make the hardware work.
  • Application software — lets the user do tasks: word processor, spreadsheet, database, graphics editing, video editing, CAD, audio editing.
  • System software — runs and manages the computer: operating system, utilities (anti-virus, backup, file compression, defragmentation), device drivers, compilers, linkers.

Internal components

  • CPU 중앙처리장치 — processes instructions and data (fetch–decode–execute); a microprocessor is a CPU on one chip.
  • Motherboard — main circuit board connecting all components.
  • Graphics card — processes images for the monitor. Sound card — converts digital sound to signals for speakers. NIC — connects the computer to a network.
  • Internal storage — HDD / SSD inside the computer.

RAM vs ROM — the most-asked comparison

Point of comparisonRAM 램ROM 롬
Volatile?Volatile — contents lost when power is offNon-volatile — contents kept without power
Read / writeCan be read from and written toRead only — contents cannot normally be changed

Model comparison
RAM is volatile, whereas ROM is non-volatile [1]. RAM can be read from and written to, whereas ROM can only be read [1]. RAM stores the programs and data currently being used, whereas ROM stores the boot-up instructions [1].

Model — explain why a laptop uses an SSD
An SSD has no moving parts, so it is less likely to be damaged if the laptop is dropped [1]. It uses less power, so the laptop’s battery lasts longer [1]. It has faster access times, so the laptop starts and opens files quickly [1].
  • Backing storage — non-volatile storage used to keep data permanently (not RAM).
  • Serial / sequential access — data read in order from the start (tape). Direct access — go straight to the data (disks, SSD).
  • Backup — a copy of data kept separately, so it can be restored if the original is lost or corrupted.
U4

Networks and the effects of using them

네트워크와 그 영향

Network hardware

  • NIC — network interface card; lets a device connect to a network; has a unique MAC address.
  • Router — connects a LAN to the internet / other networks; directs data packets using IP addresses.
  • Switch — connects devices in a LAN; sends data only to the device it is addressed to (using MAC addresses).
  • Hub — connects devices in a LAN; sends data to every device (less secure, more traffic).

Network types

  • LAN — small area (one building), usually cabled.
  • WLAN — wireless LAN using Wi-Fi access points.
  • WAN — large geographical area; the internet is the largest WAN.
  • Internet — worldwide public network of networks. Intranet — private network inside one organisation. Extranet — part of an intranet that selected outsiders can access.

Electronic conferencing

  • Video conferencing — real-time video + audio; needs webcam, microphone, speakers, software, fast internet. Saves travel time and cost; but time zones, connection problems, less personal.
  • Audio conferencing — voice only (phone or internet); cheap and simple; no visual cues.
  • Web conferencing — over the internet with screen sharing, chat, whiteboards, polls.

U6

ICT applications

ICT 응용

Communication & modelling

  • Communication media: newsletters, posters/flyers, websites, multimedia presentations, cartoons, music scores; mobile communication: SMS, phone calls, VoIP, video calls.
  • Computer modelling 컴퓨터 모델링 — a mathematical model that simulates a real system: weather forecasting, traffic lights, flight simulators, building design. Advantages: cheaper and safer than building the real thing, “what if” questions, changes are easy. Disadvantages: only as good as the data/rules; may not match reality.

Computer-controlled systems

  • Robotics in manufacturing — welding, painting, assembling. Work 24/7, consistent quality, can work in dangerous places; but expensive to set up, unemployment, cannot handle unusual tasks.
  • Sensor → microprocessor compares reading with a pre-set value → sends signal to actuator → loop continues (feedback).

Banking, retail & booking

  • ATM — withdraw cash, check balance, deposit; card + PIN checked against the bank’s records.
  • EFT — electronic funds transfer between accounts, e.g. salaries.
  • Internet banking — 24/7, no travel; but security fears, need internet, less personal.
  • POS / EFTPOS — barcode read → price looked up in stock file → stock level reduced → automatic re-order when below re-order level; card payment checked with bank.
  • Online booking (flights, cinema, events) — choose seats, instant confirmation, e-ticket; prevents double booking.
  • School management — registration (attendance), timetables, student records and grades.

Expert systems 전문가 시스템

  • Mimic a human expert: medical diagnosis, mineral prospecting, car fault diagnosis, chess, financial planning.
  • Components: user interface · knowledge base (facts) · rules base (IF–THEN rules) · inference engine (searches the knowledge base using the rules) · explanation system (explains how it reached the conclusion).
  • Answers given with a probability / percentage of being correct.

Medicine & recognition & satellites

  • Medicine — patient records, pharmacy records (allergies, interactions), 3D printing of prosthetics/implants.
  • Recognition — OMR (exam answer sheets), OCR, RFID (tracking), ANPR (car parks, speed cameras), biometrics.
  • GPS — satellites send signals; device calculates its position from at least 3 (normally 4) satellites. Used in sat-nav.
  • GIS — layers of data on a map (e.g. hospitals, roads, flood zones) for planning.

Databases (Paper 2)

데이터베이스

Structure

  • Table → records (rows, one per item) → fields (columns, one per attribute).
  • Primary key 기본 키 — a field that uniquely identifies each record (e.g. StudentID).
  • Foreign key 외래 키 — a field in one table that is the primary key of another, used to link the tables.
  • Relationship — usually one-to-many: one customer → many hires.
  • Flat-file = one table (data repeated); relational = linked tables (less duplication, fewer errors).
