One ICT lesson each week for each grade. Grades 2–5 have no exams. Weeks 9 and 18 are short checks. micro:bit work uses the browser simulator only — no hardware. Grade 2 uses mouse and keyboard on desktop computers.

⏰ The 40-minute routine

PartTimeWhat happens
🤸 Unplug5 minBody or paper warm-up. No talking.
👀 Demo3 minThe teacher shows the finished result first.
🧱 Build15 minStudents build one block at a time.
🔁 Change one thing7 minStudents change one thing and see what happens.
🌟 Showcase8 minStudents show their work. They do not need to explain.
🧹 Tidy up2 minSave, screenshot, log off.

Teacher talk stays under 3 minutes. Students learn by seeing, copying, changing and showing.

⛏️ Minecraft Education (Semester 2): classroom control

Lesson shape

Hook → Connect → Build / Code Challenge → Showcase.

Lock and release

Set Default Permission to Visitor while giving instructions. Change to Member (or release selected students) when the build starts. The teacher uses Classroom Mode.

Evidence

Camera / Portfolio and Book & Quill in the world, plus a printed Agent challenge checklist.

Tip

The Agent cannot spawn mobs — use the player or a command. Keep chat commands short and spawn mobs close to the player.
