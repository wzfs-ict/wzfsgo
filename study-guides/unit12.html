How to use this pack

How this unit is tested

Every mark in Cambridge ICT belongs to one of three assessment objectives.

ObjectiveWhat it asks you to doCommand words it usesWhere it appears

Unit 12 is examined twice over

Images appear in Paper 1 as written questions about aspect ratio, file size and editing operations. They also appear in Paper 2, where you actually place, resize, crop and wrap an image in a document and are marked on the result. The theory below is what earns the Paper 1 marks; the same knowledge is what stops you distorting an image in Paper 2.

THE GOLDEN RULE — ONE SENTENCE PER MARK

The number of marks tells you how many separate points to make. [4 marks] means FOUR points, so write FOUR sentences. Three sentences cannot score four marks however good they are.

Two more rules that cost marks in this unit specifically: Cambridge writes reflect where the software writes flip — they mean the same thing, so learn both words. And never write a brand name: “word processing software”, never the product name. No marks are awarded for brand names.

The questions that appear in this unit

These are the exact questions Cambridge repeats about images. The right-hand column is the wording that earns the mark.

Exam questionKey words that score
Explain why an image should be resized by dragging a corner handle rather than a side handle. [2]corner changes width and height in proportion · maintains the aspect ratio · side changes only one dimension · the image is distorted / stretched / squashed
Describe two factors that affect the file size of a bitmap image. [4]resolution — the number of pixels · more pixels means more data stored · colour depth — the number of bits per pixel · more bits stores more colour information
A logo must appear behind a block of text. Describe the steps needed. [3]insert the image · set text wrapping to "behind text" · use Send to Back / layering so it sits under the text
State two ways the file size of an image can be reduced. [2]reduce the resolution (fewer pixels) · reduce the colour depth (fewer bits per pixel) — these are the two the syllabus names
Explain why two images should be grouped before they are moved. [2]grouping combines them into one object · so they move and resize together · the spacing between them is kept
State the difference between brightness and contrast. [2]brightness changes how light the whole image is / every pixel by the same amount · contrast changes the difference between the light and dark areas
THE TRAPS IN THIS UNIT
  • Crop is not resize. Cropping removes part of the picture from the edges. Resizing keeps the whole picture and changes how big it is. Students lose marks every year by answering "crop it" to a resizing question.
  • Brightness is not contrast. Brightness moves every pixel lighter or darker by the same amount. Contrast changes the difference between the light and dark areas. If a question says "the light and dark areas look too similar", the answer is contrast.
  • Text wrap is section 13.1, not 12. It is taught with images because that is how it is used, but if a question names layout, expect wrapping to be the answer.

AO2 — Application

Applying what you know to a document you have not seen before.

How to spot a scenario question

A scenario question gives you a setting — a school newsletter, a poster, a report, a web page. The facts you need are the same as always. What changes is that your answer must refer to THAT document. An answer that would fit any situation scores half marks.

The scenarioWhat it is really askingThe term you need
A logo on a poster looks squashed and shortWhich handle was dragged, and what was lost?Aspect ratio · corner handle
A photo taken indoors is too dark to see facesWhich adjustment fixes overall darkness?Brightness — then contrast
Text must flow closely around a circular logoWhich wrap follows an irregular outline?Tight text wrap
A watermark must sit underneath the words of a reportWhich wrap and which layering command?Behind text · Send to Back
Three images must move across a page without losing their spacingHow do you make several objects behave as one?Group them
A photo is too large to attach to an emailWhich two properties can be lowered?Resolution · colour depth
THE AO2 SENTENCE FRAME — NAME IT, THEN TIE IT TO THE DOCUMENT

“The setting needed is ___ . This is because in this ___ the image must ___ , and ___ is the option that does that.”

Worked example: “The text wrap setting needed is Tight. This is because the logo is circular, and Tight makes the text follow the outline of the image rather than a rectangular box around it.”

AO3 — Analyse, Compare, Discuss, Recommend

Only 8% of the qualification, but the questions worth the most marks.

Command wordWhat you must produceThe trap
CompareSimilarities AND differences between two things.Writing about only one of them.
DiscussBoth sides — advantages AND disadvantages.Giving only advantages. A one-sided answer is capped at half marks.
EvaluateBoth sides, then a judgement on which is better.Stopping before you give the judgement.
JustifyA choice plus the reasons that support it.Stating the choice with no reason.
RecommendA clear decision, supported, tied to the scenario.Sitting on the fence — “both are fine”.

Getting started — the T-chart method

Before writing a discuss or evaluate answer, spend 30 seconds drawing a T on your paper. Left side FOR, right side AGAINST. Write two points on each side. Now you have four points for a [4 mark] question and you cannot accidentally write a one-sided answer.

Modelled AO3 answer

“A photograph is too large to email. Discuss whether it is better to reduce the resolution or to reduce the colour depth. [6]”

Reducing the resolution removes pixels, which lowers the file size quickly because file size depends directly on the number of pixels. However, the image then looks blurred or blocky if it is enlarged again, so detail is lost permanently.

Reducing the colour depth stores fewer bits for each pixel, which also lowers the file size and keeps the image sharp at its original size. On the other hand, areas of gradual shading may become banded, and photographs with many similar colours suffer most.

Overall, I would recommend reducing the resolution when the picture will only be viewed small, such as on screen in an email, because sharpness matters less at that size. If the photograph must stay printable, reducing the colour depth is the safer choice.

Notice the shape: two points FOR, two points AGAINST, then a recommendation tied to the situation. That is what earns the top level.
