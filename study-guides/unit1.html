How to use this pack

You already know more ICT than your marks show. Marks are lost in three places: you miss what the command word is asking, you write a fact instead of a comparison, or you leave out the technical word that carries the mark. This pack fixes those three things. Keep it beside you every time you do a past paper.

1

The golden rule

The number of marks tells you how many separate points to write.

4 marks = 4 separate points = 4 sentences.

  • Count the marks before you write. Write that many numbered sentences.
  • One sentence, one point. Do not put two points in one long sentence — the examiner may only credit one.
  • Never write more points than the marks. Extra points earn nothing and waste time.
  • If the question says "two differences" and you write three, only the first two are marked.

Command words

Name / State / GiveThe correct term only. No explanation needed.Just the term."Name the interface type that uses spoken commands." → Dialogue based.

Teacher note

“whereas” is the single highest-value word in Unit 1. It converts a zero-mark fact into a credited comparison.

5

The three-step answer: NAME · SAY · TIE

Scenario questions (museum, school office, supermarket) need all three steps.

  1. NAME the technical term. → gesture-based interface
  2. SAY what it does or what its property is. → it is controlled by movement detected by sensors, with no contact
  3. TIE it to the scenario in the question. → so, museum visitors can control the display without touching it, which is more hygienic
Don't stop early

An answer that stops at step 1 or 2 loses the scenario mark. If the question mentions a museum, your answer must mention the museum.

6

Model answers

모범 답안

Taken from the Unit 1 mark scheme. [1] marks the point where each mark is earned.

Q1 Applications and system software [4]

Applications software provides the services the user requires to solve a task [1]. Two examples are word processing software and spreadsheet software [1]. System software provides the services the computer requires to operate [1]. Two examples are an operating system and a device driver [1].

Why it scores: the words USER and COMPUTER earn the marks. Remember control software is APPLICATIONS software. Never write a brand name — brand names score zero.

Q2 Two differences between RAM and ROM [2]

RAM is volatile so its contents are lost when the power is removed, whereas ROM is non-volatile so its contents are retained [1]. RAM can be read from and written to, whereas ROM can only be read from [1].

Why it scores: each sentence compares BOTH. "RAM is volatile." on its own scores 0.

Q3 Why sensor data must be converted [2]

The output from the sensor is analogue data [1]. A computer can only process digital data, so an ADC must convert it first [1].

Extension — higher sample rate: the signal is represented more accurately [1], but more samples are stored so the file size increases [1].

Why it scores: both points name a data type. "So the computer can read it" names no data type and scores 0.

Q4 Museum interface [3]

The most suitable interface is a gesture based interface [1]. One advantage is that visitors do not need to touch the display, so it is more hygienic in a busy gallery [1]. One disadvantage is that the sensors may misread the visitor's movement [1].

Why it scores: do NOT answer "touch screen" — the question says without touching.

Q5 Desktops or laptops for a school office [4]

One advantage of a laptop is portability, because staff can carry it between offices and to meetings [1]. A laptop also runs on a battery, so it can still be used during a power cut [1]. However, one advantage of a desktop is expandability, because parts can be upgraded or repaired more easily [1]. A desktop is also harder to steal, so office records are more secure [1]. Overall, desktops are more suitable because in a fixed office expandability and security matter more than portability.

Why it scores: BOTH sides are covered. One side only is capped at 3 marks.

Q6 The role of the CPU [2]

The CPU processes the instructions entered into the computer [1]. It takes an input, processes it and produces an output, and a faster CPU processes more instructions per second [1].

Why it scores: this is a Describe question — say WHAT it does, in order. 0417 does NOT require the Control Unit / ALU breakdown, so do not waste time on it; it is not penalised but it earns nothing. Note the command word: "Describe" wants facts, not reasons.

Q7 Artificial intelligence in everyday life [4]

AI is used in medical diagnosis, where it detects disease earlier and more accurately [1]. This is positive because treatment can begin sooner [1]. AI is also used in self-driving vehicles, which reduce the need for human drivers [1]. This is negative because driving jobs and skills are lost [1].

Why it scores: each way is paired with positive/negative AND a reason. A named technology with no reason scores 0.

9

Before you hand it in

제출 전 확인
  • Did I count the marks and write that many points?
  • Does every comparison sentence mention BOTH things?
  • Did I use "whereas", "so" or "because" at least once?
  • Did I name the technical term, not a brand?
  • For Explain questions: is there a reason or a result in every point?
  • For Discuss questions: did I write both sides and a recommendation?
  • Did I mention the scenario from the question?
