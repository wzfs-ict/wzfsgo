Bulk Download — teacher tool

Rather than clicking every chip above, this PowerShell script fetches all direct-download papers into folders organised by exam series. It skips files you already have, so you can re-run it safely to pick up anything that failed.

Copied.

How to run it: open Notepad, paste, and save as Download-0417.ps1. Then right-click the file → Run with PowerShell. Papers land in your Downloads folder under IGCSE-ICT-0417. Windows may warn about running scripts — that warning is doing its job, so only run scripts you have read yourself first.
