Grade 9

Units 11 – 13

Theory and practical, mixed

  • 📁 11 File management — manage files (folders, meaningful names, generic vs application-specific formats, save and export) and reduce file size (lossy / lossless compression, zipped files)
  • 🖼️ 12 Images — place and resize with / without the aspect ratio, crop, rotate, reflect, colour depth, brightness and contrast, reduce resolution
  • 📐 13 Layout — 13.1 create or edit a document (import objects, text wrapping) · 13.2 tables · 13.3 headers and footers with automated fields

Theory is examined in Paper 1. The same skills are used in every practical (Papers 2 and 3).
